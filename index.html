Foundations · الأساسيات

What is a number system? إيه هو نظام العد أصلاً؟

A number system combines symbols, a base (b), and place values so digit position determines its weight.

1 · Symbols الرموز اللي بنستخدمها

0 1   0–7   0–9   0–F

Each system picks b distinct symbols starting from 0 up to b−1.

2 · Base / Radix أساس النظام (الـ Base)

b symbols → carry at b

What happens when a digit passes b−1? It resets to 0 and carries 1 to the next place.

( للمعرفة فقط )

3 · Place Value قيمة كل خانة

value = digit × bn

Moving one step left multiplies the place weight by b (b⁰, b¹, b²…).

How order changes value ترتيب الخانات بيفرق قد إيه

In 13 vs 31, the digits are identical, but their positions changed — so their weights changed.

Same quantity, four forms

1310 = 11012 = 158 = D16

The value stays identical; only the base notation changes.

Base 2 & Base 8

Binary and Octal الثنائي والثماني بالتفصيل

Binaryالثنائي (أساس 2)
base 2
1 · الأسس بنرقّم الخانات من اليمين للشمال: 2⁰=1 2¹=2 2²=4 2³=8 2⁴=16
2 · الضرب والجمع اللي منوّر بـ 1 في 10110₂ هو: 16 + 4 + 2 = 22₁₀ (والبايت = 8 بت).
Octalالثماني (أساس 8)
base 8
1 · الأسس أوزان الثماني من اليمين: 8⁰=1 8¹=8 8²=64
2 · الفكرة في 26₈ ضربنا 6×1=6 و 2×8=16 فالمجموع طلع 22₁₀، وكل رقم ثماني بياخد 3 بت عشان 8=2³.
Notice that 10110₂, 26₈, and 22₁₀ all represent the exact same quantity.

Base 10 & Base 16

Decimal and Hexadecimal العشري والسادس عشري

Decimalالنظام العشري (أساس 10)
base 10
34710 = 300 + 40 + 7

MSB (أعلى خانة في القيمة) is on the far left; LSB (أقل خانة في القيمة) is on the far right.

1 · الأسس أوزان العشري من اليمين: 10⁰=1 10¹=10 10²=100
2 · الحساب 7×1=7، 4×10=40، 3×100=300 → الناتج 347₁₀ (الـ MSB على الشمال خالص والـ LSB على اليمين خالص).
Hexadecimalالنظام السادس عشري (أساس 16)
base 16
1A16 = (1×16) + (10×1) = 2610
1 · الأسس والتجميع أوزان السادس عشري: 16⁰=1 16¹=16 وكل خانة Hex = 4 بت (Nibble).
2 · الحساب في 1A₁₆: الـ A يعني 10، يبقى (1×16) + (10×1) = 16 + 10 = 26₁₀.

Working Through Decimal التحويل من وإلى العشري

Any Base → Decimal الضرب في الأساس وجمعهم

11012 = 8 + 4 + 0 + 1 = 1310
1 · كتابة الأسس من اليمين للشمال على 1101₂: 2⁰=1 2¹=2 2²=4 2³=8
2 · ناتج الجمع (1×8) + (1×4) + (0×2) + (1×1) = 8 + 4 + 0 + 1 = 13₁₀.

Decimal → Base b القسمة المتكررة

13÷2→r1 · 6÷2→r0 · 3÷2→r1 · 1÷2→r1 → 11012
ملاحظة نقسم الناتج على الأساس b باستمرار، ونرتب البواقي من تحت لفوق للحصول على الرقم في النظام الجديد.

Conversions · Part 2

Shortcut Grouping التحويل السريع بالتجميع

Because 8 = 2³ and 16 = 2⁴, we group bits directly instead of going through Decimal.

Binary ↔ Octal تجميع كل 3 بت

010 1102 → 2 68 = 268
1 · التجميع بأسس 2 عشان 8 = 2³، بنقسم من اليمين كل 3 بت بأوزان 2⁰ 2¹ 2² ونكمّل الشمال بصفر لو ناقص: 010 | 110.
2 · القراءة 010₂ = 2 و 110₂ = 4+2 = 6 → يطلع 26₈.

Binary ↔ Hexadecimal تجميع كل 4 بت

1010 11112 → A F16 = AF16
1 · التجميع بأسس 2 عشان 16 = 2⁴، بنقسم من اليمين كل 4 بت بأوزان 2⁰ 2¹ 2² 2³: 1010 | 1111.
2 · القراءة 1010₂ = 8+2 = 10 (A) و 1111₂ = 8+4+2+1 = 15 (F) → يطلع AF₁₆.

Conversions · Part 3

Fractional Numbers تحويل الكسور بعد العلامة

Digits after the Radix Point (العلامة العشرية/الثنائية) use negative powers: b⁻¹, b⁻², b⁻³…

Binary Fraction → Decimal

10.1012 = 2 + 0.5 + 0.125 = 2.62510
1 · الأسس السالبة بعد العلامة بنمشي يمين بأسس سالبة: 2⁻¹=0.5 2⁻²=0.25 2⁻³=0.125.
2 · الجمع الجزء الصحيح 10₂ = 2 + الكسر (1×0.5) + (0×0.25) + (1×0.125) = 0.625 → يبقى 2.625₁₀.

Decimal Fraction → Base b الضرب المتكرر

0.625×2=1.25 → 0.25×2=0.5 → 0.5×2=1.0 → .1012
1 · الضرب المتكرر بنضرب الكسر في الأساس (×2): 0.625×2=1.25، 0.25×2=0.5، 0.5×2=1.0.
2 · أخذ الصحيح بناخد الجزء الصحيح من فوق لتحت (1، 0، 1) لحد ما الكسر يبقى 0 → .101₂.

Core Rules to Remember

  • Base b uses digits 0 through b−1.
  • To Decimal: sum of digit × bposition.
  • From Decimal: divide integers, multiply fractions.
  • 3 bits = 1 Octal digit; 4 bits = 1 Hex digit.
  • Negative integers: Two's Complement (invert + 1).

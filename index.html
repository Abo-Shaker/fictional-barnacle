Why Beginners Jump to Code — and Why Pros Draw First

What a Flowchart Really Is (Beyond "Boxes & Arrows")

A flowchart is a state-and-decision map. Every arrow represents time moving forward as variables change values or conditions split reality into two universes: True vs. False.

بصراحة ومن واقع البرمجة: الغلطة اللي بيقع فيها أغلب المبتدئين إنه يفتح الكود ويكتب سطر ورا سطر وهو لسه مش متخيل: إمتى الكود يقف؟ وإيه اللي يحصل لو المستخدم دخل رقم سالب أو صفر أو كرر المحاولة غلط 5 مرات؟ خريطة التدفق بتجبرك تواجه الحالات دي على ورق قبل ما تضيع ساعتين في تتبع أخطاء الكود.
How I Mentally Break Down Any Problem (5 Habits)
  1. Clarify the contract: What comes in, what goes out, and what counts as invalid input?
  2. Track state variables: Name every variable that changes and write its starting value.
  3. Draw the happy path first: Get normal inputs working from Start to End.
  4. Attack edge cases & loops: Test 0, negatives, boundaries, and exit conditions.
  5. Dry-run with a trace table: Walk every arrow like a slow-motion CPU.
الفرق بين "فاهم الكود" و"فاهم المنطق": لو غيرنا لغة البرمجة من Python لـ C++ أو Java أو Dart، القواعد النحوية (Syntax) بتتغير، لكن منطق القرارات والحلقات في خريطة التدفق بيفضل زي ما هو. اللي بيتقن الخرائط بيكتب كود أنظف في أي لغة.
Edge-Case Radar
Forces you to ask "what if this condition is false?" before a bug reaches production.
Loop Termination Proof
Makes it obvious whether a loop variable actually moves closer to the exit condition.
Clear Communication
Explains complex business rules to teammates or professors in seconds without jargon.
Faster Debugging
When output looks wrong, you immediately know which branch or loop iteration went off track.

03 · Structural Theorem of Programming

Sequence, Selection, and Iteration

1. Sequence
التسلسل

Order matters! Swapping b = a * 2 before a = 5 uses stale or undefined data.

a = 5
b = a * 2
print(b)  # 10
تنبيه عملي: في التسلسل، ترتيب السطور هو كل حاجة. أي متغير لازم يتعرف ويتحسب قبل ما نستخدمه.
2. Selection
الاختيار (If/Else)

Splits flow based on a boolean expression. Both branches usually merge back before continuing.

if x > 0:
    print("Positive")
else:
    print("Non-positive")
تنبيه عملي: اسأل نفسك دايماً: "إيه اللي يحصل لما الشرط يكون No؟" عشان متنساش حالة كاملة.
3. Iteration (Loop)
التكرار (Loop)

Needs 3 parts: init before the loop, condition to stay in, and update inside to reach exit.

i = 1
while i <= 3:
    print(i)
    i = i + 1
تنبيه عملي: لو نسيت تحديث العداد (i = i + 1) أو عكست اتجاهه، هتدخل في حلقة لا نهائية (Infinite Loop).

09 · Engineering Discipline

Clean Diagrams vs. Spaghetti Flowcharts

Do — Clear & Maintainable
  • Use one Start and clearly defined End(s) without dangling paths.
  • Keep primary flow top-to-bottom; use left/right branches cleanly for decisions and loops.
  • Keep each box focused on one clear responsibility.
  • Always label both outcomes (Yes / No) on every diamond.
القاعدة الذهبية: لو زميلك أو دكتور المادة فهم الخريطة من أول نظرة من غير ما يشرحها، يبقى رسمك ممتاز.
Don't — Classic Bugs & Anti-Patterns
  • Avoid crossing arrows; reorganize nodes or split into clean sub-steps.
  • Never split two arrows out of a Process rectangle without a diamond.
  • Never leave a loop without a progress step toward termination.
  • Don't hide critical logic inside vague text like "do calculations".
أكبر غلطة بتضيع درجات: سهم خارج من مستطيل عملية بدون معين قرار، أو حلقة تكرار متغيرها ثابت للأبد.

11 · الخلاصة السريعة قبل الامتحان أو الكود

روشتة النجاة السريعة في خرائط التدفق

إمتى أختار أنهي شكل؟
  • بيضاوي (Start/End): أول خطوة وآخر خطوة بس.
  • متوازي أضلاع (I/O): قراءة من المستخدم أو طباعة نتيجة.
  • مستطيل (Process): حسابات أو تغيير قيمة متغير (x = x + 1).
  • معين (Decision): سؤال إجابته Yes أو No فقط.
أشهر 4 فخاخ بتوقع الطلبة
  • تبدأ sum = 0 صح، لكن تبدأ prod = 0 غلط (الضرب يبدأ بـ 1).
  • تفترض max = 0 وتنسى إن الأرقام ممكن تبقى سالبة كلها.
  • تكتب if x >= 50 قبل if x >= 85 في التقديرات.
  • تعمل حلقة تكرار من غير سطر يغير شرط الخروج فتلف للأبد.

What is a number system? إيه هو نظام العد أصلاً؟

A number system combines symbols, a base (b), and place values so digit position determines its weight.

1 · Symbols الرموز اللي بنستخدمها

0 1   0–7   0–9   0–F

Each system picks b distinct symbols starting from 0 up to b−1.

2 · Base / Radix أساس النظام (الـ Base)

b symbols → carry at b

What happens when a digit passes b−1? It resets to 0 and carries 1 to the next place.

( للمعرفة فقط )

3 · Place Value قيمة كل خانة

value = digit × bn

Moving one step left multiplies the place weight by b (b⁰, b¹, b²…).

How order changes value ترتيب الخانات بيفرق قد إيه

In 13 vs 31, the digits are identical, but their positions changed — so their weights changed.

Same quantity, four forms

1310 = 11012 = 158 = D16

The value stays identical; only the base notation changes.

Base 10 & Base 16

Decimal and Hexadecimal العشري والسادس عشري

Decimalالنظام العشري (أساس 10)
base 10
34710 = 300 + 40 + 7

MSB (أعلى خانة في القيمة) is on the far left; LSB (أقل خانة في القيمة) is on the far right.

1 · الأسس أوزان العشري من اليمين: 10⁰=1 10¹=10 10²=100
2 · الحساب 7×1=7، 4×10=40، 3×100=300 → الناتج 347₁₀ (الـ MSB على الشمال خالص والـ LSB على اليمين خالص).

base 16
1A16 = (1×16) + (10×1) = 2610
1 · الأسس والتجميع أوزان السادس عشري: 16⁰=1 16¹=16 وكل خانة Hex = 4 بت (Nibble).
2 · الحساب في 1A₁₆: الـ A يعني 10، يبقى (1×16) + (10×1) = 16 + 10 = 26₁₀.

Working Through Decimal التحويل من وإلى العشري

Any Base → Decimal الضرب في الأساس وجمعهم

11012 = 8 + 4 + 0 + 1 = 1310
1 · كتابة الأسس من اليمين للشمال على 1101₂: 2⁰=1 2¹=2 2²=4 2³=8
2 · ناتج الجمع (1×8) + (1×4) + (0×2) + (1×1) = 8 + 4 + 0 + 1 = 13₁₀.

Decimal → Base b القسمة المتكررة

13÷2→r1 · 6÷2→r0 · 3÷2→r1 · 1÷2→r1 → 11012
ملاحظة نقسم الناتج على الأساس b باستمرار، ونرتب البواقي من تحت لفوق للحصول على الرقم في النظام الجديد.

Conversions · Part 2

Shortcut Grouping التحويل السريع بالتجميع

Because 8 = 2³ and 16 = 2⁴, we group bits directly instead of going through Decimal.

Binary ↔ Octal تجميع كل 3 بت

010 1102 → 2 68 = 268
1 · التجميع بأسس 2 عشان 8 = 2³، بنقسم من اليمين كل 3 بت بأوزان 2⁰ 2¹ 2² ونكمّل الشمال بصفر لو ناقص: 010 | 110.
2 · القراءة 010₂ = 2 و 110₂ = 4+2 = 6 → يطلع 26₈.

Binary ↔ Hexadecimal تجميع كل 4 بت

1010 11112 → A F16 = AF16
1 · التجميع بأسس 2 عشان 16 = 2⁴، بنقسم من اليمين كل 4 بت بأوزان 2⁰ 2¹ 2² 2³: 1010 | 1111.
2 · القراءة 1010₂ = 8+2 = 10 (A) و 1111₂ = 8+4+2+1 = 15 (F) → يطلع AF₁₆.

Conversions · Part 3

Fractional Numbers تحويل الكسور بعد العلامة

Digits after the Radix Point (العلامة العشرية/الثنائية) use negative powers: b⁻¹, b⁻², b⁻³…

Binary Fraction → Decimal

10.1012 = 2 + 0.5 + 0.125 = 2.62510
1 · الأسس السالبة بعد العلامة بنمشي يمين بأسس سالبة: 2⁻¹=0.5 2⁻²=0.25 2⁻³=0.125.
2 · الجمع الجزء الصحيح 10₂ = 2 + الكسر (1×0.5) + (0×0.25) + (1×0.125) = 0.625 → يبقى 2.625₁₀.

Decimal Fraction → Base b الضرب المتكرر

0.625×2=1.25 → 0.25×2=0.5 → 0.5×2=1.0 → .1012
1 · الضرب المتكرر بنضرب الكسر في الأساس (×2): 0.625×2=1.25، 0.25×2=0.5، 0.5×2=1.0.
2 · أخذ الصحيح بناخد الجزء الصحيح من فوق لتحت (1، 0، 1) لحد ما الكسر يبقى 0 → .101₂.

Core Rules to Remember

  • Base b uses digits 0 through b−1.
  • To Decimal: sum of digit × bposition.
  • From Decimal: divide integers, multiply fractions.
  • 3 bits = 1 Octal digit; 4 bits = 1 Hex digit.
  • Negative integers: Two's Complement (invert + 1).

Binary & Grouping

Group 3 bits for Octal (0–7) and 4 bits for Hexadecimal (0–9, A–F) from the radix point outward.

Conversions

Multiply by bⁿ to reach Base 10; divide integer parts and multiply fractional parts by target base b.

Base Arithmetic

Carry 1 when a column reaches or exceeds b; borrow b when subtracting a larger digit.
